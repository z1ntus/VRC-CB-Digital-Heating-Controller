# Build and release notes

This file is a checklist for preparing the first public GitHub release.

## Before release

- [ ] Add the final firmware source files
- [ ] Add the final `.kicad_pro`, `.kicad_sch` and `.kicad_pcb` files
- [ ] Add the final Gerber/drill files
- [ ] Add the BOM
- [ ] Add PCB revision number
- [ ] Add photographs
- [ ] Document the Arduino Nano ESP32 version
- [ ] Document the NTC used on pins 22/23
- [ ] Document wiring and connector pinout
- [ ] Document firmware installation
- [ ] Document configuration
- [ ] Add complete GPL-3.0-or-later licence text
- [ ] Add complete CERN-OHL-S-2.0 licence text
- [ ] Verify all third-party libraries and their licences
- [ ] Verify all third-party KiCad symbols/footprints and their licences
- [ ] Review the safety disclaimer
- [ ] Create the first Git tag/release
